# CallOfJelly

**CallOfJelly** is a Java-based game created as a collaborative programming project. The game features multiple maps, playable characters, perks, custom graphics, music, sound effects, and more.

## 🎮 Playing CallOfJelly

CallOfJelly includes both a playable Java version and a packaged Windows version.

### Windows

Windows users can launch the game using:

**`Call Of Jelly WINDOWS.exe`**

The Windows version includes its own Java runtime, so Java does not need to be installed separately.

> **Important:** Keep the EXE together with the included `app` and `runtime` folders. These files are required for the Windows version to run.

### Windows, macOS, and Linux

The cross-platform Java version is:

**`CallOfJelly Playable.jar`**

CallOfJelly was developed using **Java SE 24 / JDK 24**. Java SE 24 / JDK 24 or later is recommended for running the JAR version.

You can normally open the JAR directly. If it does not launch, open a terminal or command prompt in the CallOfJelly folder and run:

```bash
java -jar "CallOfJelly Playable.jar"
```

## 🛠️ Building From Source

The complete source code is included in this repository.

CallOfJelly was developed using:

- **Java SE 24 / JDK 24**
- **Apache NetBeans**
- **Apache Ant**

To build the project:

1. Open the project in Apache NetBeans.
2. Make sure **JDK 24** or a compatible JDK is configured.
3. Select **Clean and Build Project**.
4. The compiled JAR will be generated in the `dist` folder.

The project also uses the NetBeans **AbsoluteLayout** library, which is included with the project and is required when building and running the game.

- Your Java version if using the JAR

- Any error message you received
